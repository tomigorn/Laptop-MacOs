# Keyboard Shortcuts Cheat Sheet

---

## macOS System

| Shortcut | Action |
|---|---|
| `Cmd + Space` | Spotlight search |
| `Cmd + ,` | Open app preferences |
| `Cmd + Q` | Quit app |
| `Cmd + W` | Close window/tab |
| `Cmd + Shift + 3` | Screenshot full screen |
| `Cmd + Shift + 4` | Screenshot selection |
| `Cmd + Shift + 5` | Screenshot window |
| `Cmd + Shift + 5` | Screenshot/screen recording menu |
| `Ctrl + Cmd + Q` | Lock screen |
| `Cmd + Option + Esc` | Force quit menu |

---

## Finder

| Shortcut | Action |
|---|---|
| `Cmd + N` | New Finder window |
| `Cmd + T` | New tab |
| `Cmd + Shift + N` | New folder |
| `Cmd + Delete` | Move to Trash |
| `Cmd + Shift + Delete` | Empty Trash |
| `Cmd + I` | Get Info |
| `Cmd + Shift + .` | Show/hide hidden files |
| `Space` | Quick Look preview |
| `Cmd + Up` | Go to parent folder |
| `Cmd + [` / `Cmd + ]` | Back / Forward |

---

## Text Editing

| Shortcut | Action |
|---|---|
| `Cmd + C/X/V` | Copy / Cut / Paste |
| `Cmd + Z` | Undo |
| `Cmd + Shift + Z` | Redo |
| `Cmd + A` | Select all |
| `Cmd + F` | Find |
| `Option + Left/Right` | Move by word |
| `Cmd + Left/Right` | Move to line start/end |
| `Cmd + Up/Down` | Move to document start/end |
| `Option + Delete` | Delete word back |
| `Cmd + Delete` | Delete to line start |

---

## Terminal / Shell

| Shortcut | Action |
|---|---|
| `Ctrl + C` | Interrupt / kill process |
| `Ctrl + Z` | Suspend process |
| `Ctrl + D` | EOF / exit shell |
| `Ctrl + L` | Clear screen |
| `Ctrl + A` / `Ctrl + E` | Go to line start / end |
| `Ctrl + U` | Clear line |
| `Ctrl + W` | Delete word back |
| `Ctrl + R` | Reverse history search |
| `Ctrl + G` | Cancel search |
| `!!` | Repeat last command |
| `!$` | Last argument of previous command |

---

## Browser

| Shortcut | Action |
|---|---|
| `Cmd + T` | New tab |
| `Cmd + Shift + T` | Reopen closed tab |
| `Cmd + W` | Close tab |
| `Cmd + L` | Focus address bar |
| `Cmd + R` | Reload |
| `Cmd + Shift + R` | Hard reload |
| `Cmd + Option + I` | Dev tools |
| `Cmd + 1..9` | Switch to tab by number |
| `Cmd + Option + Left/Right` | Previous / Next tab |
